# lokesh-architecture-2026

Modern “resume on the web” personal site for Lokesh Paduchuri, built with Angular 20.
Focused on *what I do* and *how I do it* — with modal-based case studies, strong UX polish, SEO fundamentals, and performance-first delivery.

---

## ✨ Highlights
- Angular 20 (standalone components + router)
- Resume-style layout + print-friendly `/resume`
- Work grid with **modal case studies** and deep-link support
- Dark/Light theme toggle (system-aware + `localStorage` persistence)
- SEO fundamentals (per-route tags + JSON-LD)
- Deployment-ready for S3 + CloudFront

## 🧱 Tech Stack
- Angular 20
- Tailwind CSS
- CSS transitions/keyframes only

## 🚀 Run locally
```bash
npm install
npm start
```

## 🧪 Quality checks
```bash
npm run lint
npm run build
```

## ☁️ Deploy
```bash
npm run deploy
```

Update placeholders in `package.json`:
- `YOUR_BUCKET_NAME`
- `YOUR_DISTRIBUTION_ID`
